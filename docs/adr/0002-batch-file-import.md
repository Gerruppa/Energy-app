# Import wsadowy z plików zamiast pobierania danych z eLicznika

Użytkownik analizuje dane raz na 1–4 tygodnie i nie potrzebuje podglądu na żywo, więc dane wchodzą wyłącznie przez upload PDF-ów faktur i ręcznie pobranych eksportów z eLicznika. Odpada logowanie do serwisu Tauron i nieoficjalne API, które psuje się przy zmianach po stronie Taurona, a aplikacja nie przechowuje haseł.
